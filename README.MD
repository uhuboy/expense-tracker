# Python GUI Expense Tracker (Learning Project)

โปรเจกต์เรียนรู้การสร้างโปรแกรมระบบบันทึกรายรับ–รายจ่ายด้วย Python ตั้งแต่ระดับเริ่มต้นจนถึงการนำไปรันบน Android ผ่านบทเรียน 11 บท

## 📋 รายละเอียดบทเรียน

| บทที่ | หัวข้อ | สิ่งที่ได้เรียนรู้ |
| :--- | :--- | :--- |
| 01 | พื้นฐาน GUI | `tkinter`, `Label`, `Entry`, `Button`, `grid()` |
| 02 | หน้าจอ Login | การตรวจสอบ Username/Password, `messagebox` |
| 03 | จัดการหลายหน้าจอ | `Frame`, `tkraise()`, การออกแบบโครงสร้างคลาส |
| 04 | เชื่อมต่อ SQLite | การสร้างไฟล์ฐานข้อมูลและตารางอัตโนมัติ (`sqlite3`) |
| 05 | แสดงรายการข้อมูล | `ttk.Treeview`, การใช้ Scrollbar, การแสดงผลตาราง |
| 06 | เพิ่มข้อมูล | การสร้างแบบฟอร์ม, การตรวจสอบความถูกต้องของข้อมูล (Validation) |
| 07 | แก้ไขข้อมูล | การใช้หน้าจอเดิม (Edit Mode), คำสั่ง SQL `UPDATE` |
| 08 | ลบข้อมูล | การลบด้วย `id`, หน้าต่างยืนยันการลบ (`askyesno`) |
| 09 | ค้นหาและกรอง | SQL `LIKE`, `WHERE`, การเรียงลำดับข้อมูล |
| 10 | Dashboard & Refactoring | การสรุปข้อมูลรายเดือน, การจัดระเบียบโค้ด (Clean Code) |
| 11 | รันบน Android | การเปลี่ยนจาก Tkinter เป็น `Kivy`, การสร้าง APK ด้วย `Buildozer` |

## 🚀 วิธีการใช้งาน

### ความต้องการระบบ
- Python 3.x
- สำหรับบทที่ 11: Linux/macOS (แนะนำ) หรือ WSL สำหรับ Buildozer

### ขั้นตอนการรัน
1. Clone โปรเจกต์นี้:
   ```bash
   git clone https://github.com/uhuboy/expense-tracker.git
   cd expense-tracker
   ```
2. รันโปรแกรมในบทที่ต้องการ (เช่น บทที่ 9):
   ```bash
   python chapter09.py
   ```

## 🛠 เทคโนโลยีที่ใช้
- **GUI:** `tkinter`, `ttk`, `Kivy` (สำหรับ Android)
- **Database:** `sqlite3`
- **Packaging:** `Buildozer` (สำหรับ Android)
